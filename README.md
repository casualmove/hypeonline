# hypeonline
A website for any rewrite project

## Функциональные возможности

1. **Главный экран (Hero Section)**:
   - Информационный блок с описанием игрового режима.
   - Кнопка быстрого перехода к скачиванию лаунчера с автоскроллом.
   - Интерактивный промо-видеоплеер.
   - Анимированная бегущая строка (Marquee).

2. **Блок особенностей ("У нас есть")**:
   - Презентация игровых механик: ОПГ, автопарк, скины персонажей.
   - Графическое оформление карточек с поддержкой фоллбеков.

3. **Секция загрузки (Download Section)**:
   - Директ-ссылка на актуальную версию Android APK (`app-release.apk`).
   - Директ-ссылка на десктопный лаунчер (`Launcher.zip`).

4. **Мобильная навигация**:
   - Адаптивное выпадающее меню (Drawer UI).
   - Быстрые ссылки на социальные сети (ВКонтакте, Discord).

5. **Правовая документация**:
   - Ссылки на пользовательское соглашение, политику конфиденциальности и условия оплаты.

## Инструкция по развертыванию

### Требования к серверу
* Веб-сервер: Nginx / Apache HTTP Server.
* Поддержка PHP: Версия 7.4 и выше (для работы `donate.php`).
