

# HYPE RUSSIA — Официальный веб-портал игрового проекта

Профессиональный лендинг и веб-интерфейс мобильного ролевого онлайн-проекта HYPE RUSSIA (CRMP Android / GTA Russia). Репозиторий содержит полный исходный код клиентской веб-части, адаптивную верстку, скрипты интеграции и конфигурации аналитических систем.

## Архитектурные особенности

Проект разработан с учетом современных стандартов веб-разработки:
* Использование методологии **БЭМ (Блок-Элемент-Модификатор)** для наименования CSS-классов.
* Кроссбраузерная и адаптивная верстка с оптимизацией под устройства с различным разрешением экрана.
* Оптимизация производительности: предзагрузка критических шрифтов (`<link rel="preload">`) и использование современного формата изображений `WebP`.
* Поддержка темного режима интерфейса (`theme-color: #121212`).

## Технологический стек

### Frontend
| Компонент | Технология / Библиотека | Назначение |
| :--- | :--- | :--- |
| Разметка | HTML5 (Semantic Markup) | Семантическая структура страниц |
| Стилизация | CSS3, Vendor CSS | Стили проекта и адаптивные сетки |
| Типографика | Manrope, Rubik Mono One | Корпоративные веб-шрифты |
| JS-Ядро | JavaScript (ES6+), jQuery 3.7.1 | Интерактивность, манипуляции DOM |
| Модальные окна | Lity.js, Lightbox.js | Просмотр медиаконтента и видео |
| Эффекты | jQuery Reveal | Анимации появления элементов |

### Интеграции
* **Яндекс.Метрика**: Трекинг посещаемости, Вебвизор, Ecommerce-события.
* **Lava Payment Gateway**: Мета-конфигурация платежной системы.

## Функциональные возможности

1. **Главный экран (Hero Section)**:
   - Информационный блок с описанием игрового режима.
   - Кнопка быстрого перехода к скачиванию лаунчера с автоскроллом.
   - Интерактивный промо-видеоплеер.
   - Анимированная бегущая строка (Marquee).

2. **Блок особенностей ("У нас есть")**:
   - Презентация игровых механик: ОПГ, автопарк, скины персонажей.
   - Графическое оформление карточек с поддержкой фоллбеков.

3. **Секция загрузки (Download Section)**:
   - Директ-ссылка на актуальную версию Android APK (`app-release.apk`).
   - Директ-ссылка на десктопный лаунчер (`Launcher.zip`).

4. **Мобильная навигация**:
   - Адаптивное выпадающее меню (Drawer UI).
   - Быстрые ссылки на социальные сети (ВКонтакте, Discord).

5. **Правовая документация**:
   - Ссылки на пользовательское соглашение, политику конфиденциальности и условия оплаты.
